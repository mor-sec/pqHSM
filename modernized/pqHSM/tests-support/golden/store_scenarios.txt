# Phase 2 slice 3 (token store) scenarios. ONE script, run by two interpreters:
#   - tests-support/golden/gen_store.c runs it against the LEGACY C fhsm_token.c and records
#     every step's output in golden/store/steps.tsv (regen_store.sh copies this file there too);
#   - token/tests/store_common/scenario.rs runs the same lines against the Rust API and compares.
#
# Grammar (whitespace-separated; key=value arguments; numbers decimal or 0x):
#   scenario NAME [from=tok:SCENARIO|corpus:FILE]   start; from= copies a C-written start file
#   PIN    SO | USER | WRONG | NEW | lit:TEXT        (all invented; none from the legacy tree)
#   BYTES  - (none / NULL) | hex:.. | pat:BASE:N (BASE, BASE+1, ...) | zero:N | rep:C:N | txt:T
#   LABEL  a bare word, or any BYTES form
#   t=B    on a token op: use the second handle (default A)
# Ops are implemented twice, in store_common/scenario.rs (`Run::op`, `Run::token_op`) and gen_store.c (`run_op`).
# Every op line's output also carries one `audit=event/ROLE/rv/params` per audit record.
